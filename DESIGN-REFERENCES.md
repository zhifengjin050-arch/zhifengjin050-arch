# Design references and applied decisions

This portfolio uses original SVG assets and project-specific writing. The references below informed composition and reading patterns; their personal content, artwork and achievements were not copied.

- [DenverCoder1](https://github.com/DenverCoder1/DenverCoder1): project-card galleries, visible video entry points and collapsible detail sections. Applied as a three-project demo gallery and expandable technical implementation notes.
- [sindresorhus](https://github.com/sindresorhus/sindresorhus): a clear, direct entry point to featured work. Applied as visible demo, architecture and repository actions below the hero.
- [Awesome GitHub Profile README](https://github.com/abhisheknaiidu/awesome-github-profile-readme): used to compare descriptive, typing and minimal profile patterns. Retained the gold identity, searchable project text and self-hosted SVG typography.
- [lenyanjgk](https://github.com/lenyanjgk): requested visual reference for ivory/gold styling, icon-box headings and chapter dividers. Implemented with original theme-aware SVGs and gradient title text.

## Maintenance

Edit profile.config.json and profile.en.json, then run python generate.py. Both language editions include the same core project gallery and navigation structure. Gallery images come from each project's existing demo covers; they link to the corresponding GitHub Pages demo.
